# cuteit Tutorial

## Overview
`cuteit` obfuscates an IPv4 address in alternate representations.

## Prerequisites
- Valid IPv4 address input.

## Interactive Steps
1. Run `fsociety`.
2. Select `obfuscation`.
3. Select `cuteit`.
4. Enter address at `Enter a ip:`.

## Practical Example
Input:

```text
Enter a ip: 192.168.1.100
```

Executed pattern:

```bash
python3 Cuteit.py 192.168.1.100
```

## Expected Output
- Obfuscated/alternate formats for the provided IP.

## Troubleshooting
- Use IPv4 format without protocol or port.
- Retry with a valid numeric IP string.

## Safety Notes
Use obfuscation techniques only in approved security testing or training contexts.
