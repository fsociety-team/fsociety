# suggest_tool Tutorial

## Overview
`suggest_tool` opens the project issue template to request a new tool integration.

## Prerequisites
- Browser access from your environment.
- GitHub account (to submit the issue).

## Interactive Steps
1. Run `fsociety`.
2. Select `utilities`.
3. Select `suggest_tool`.
4. Your browser opens the tool-request issue template.

## Practical Example
Use the opened issue template to provide:
- Tool name
- Repository URL
- Why it should be integrated
- Typical use case

## Expected Output
A browser tab opens to:

```text
https://github.com/fsociety-team/fsociety/issues/new?...template=---tool-request.md
```

## Troubleshooting
- If no browser opens, copy the URL manually into a browser.
- Check desktop/browser integration on headless systems.

## Safety Notes
Submit legitimate, security-focused tools and avoid abusive requests.
