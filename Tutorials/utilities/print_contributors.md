# print_contributors Tutorial

## Overview
`print_contributors` fetches and prints contributor usernames from the project GitHub API.

## Prerequisites
- Internet connectivity.
- Access to GitHub API from your environment.

## Interactive Steps
1. Run `fsociety`.
2. Select `utilities`.
3. Select `print_contributors`.

## Practical Example
No input is required. The utility automatically fetches and prints contributors sorted by contribution count.

## Expected Output
- ASCII banner followed by contributor usernames.
- Output is ordered by highest contributions first.

## Troubleshooting
- If request fails, verify internet access and GitHub API reachability.
- Retry later if rate-limited.

## Safety Notes
This utility is informational and does not perform target interaction.
